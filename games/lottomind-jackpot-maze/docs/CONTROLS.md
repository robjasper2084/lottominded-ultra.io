# Controls

## Desktop

- Move: arrow keys or WASD
- Activate equipped Gold Mind Shield: Space
- Pause: P or the Pause button
- Mute: M or the start-screen setting
- Quit a run: Quit Run

## Mobile and tablet

- Move: large on-screen D-pad
- Activate power-up: POWER button
- Pause and quit: top action buttons

The play surface uses `touch-action: none` to prevent accidental page scrolling while playing. A player is invulnerable until the first movement input so an idle start cannot cost a life.
