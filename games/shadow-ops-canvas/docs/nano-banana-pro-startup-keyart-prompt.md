# Nano Banana Pro Startup Key Art Prompt

Use Higgsfield Nano Banana Pro to create a polished title-card key art image for the Robot Rahbe / Shadow Ops Canvas browser game.

Prompt:

Create premium 16:9 cinematic key art for a side-scrolling cyber-jungle run-and-gun browser game called ROBOT RAHBE. The scene should look like live gameplay art, not a product photo: a black and gold sci-fi jungle vault platform, purple neon fog, magenta heart bullets, small drones, robot dogs, shield robots, a glowing cyber-vault heart reactor in the distance, and readable platform silhouettes. Use deep purples, black metal, gold circuit accents, magenta energy, and soft cyan HUD glow. Make it feel like a modern arcade game splash image inspired by the current game screen. No UI text, no logos, no menu, no watermark, no clipped objects, no transparent checkerboard, no distorted characters. Keep the original mascot style consistent if shown, but the focus is gameplay action and world atmosphere. Clean composition with space for a title panel on the left.

Negative prompt:

No historical figures, no real-world politicians, no classroom poster, no product packaging, no random text, no unreadable glyphs, no extra arms, no cropped weapons, no checkerboard transparency artifacts, no blurry low-resolution UI screenshots.

Implementation note:

Save the final approved image as `assets/backgrounds/robot-rahbe-gameplay-keyart.png` and keep it at 16:9. The title card already references that path.
