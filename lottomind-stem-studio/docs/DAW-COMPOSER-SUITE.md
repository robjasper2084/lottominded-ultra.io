# DAW Composer Suite

LottoMind Stem Studio is a standalone browser DAW layer built on Web Audio API, Canvas, IndexedDB, File API, MediaRecorder, and optional Web MIDI. It runs from static hosting and does not require a backend.

## Browser-Safe Scope

- Song Editor arranges tracks, clips, patterns, stems, samples, scenes, and automation metadata.
- Pattern Editor creates drum and pad-based grooves.
- Piano Roll edits MIDI-style notes for built-in instruments.
- Mixer supports user-created channels, buses, sends, and Web Audio effect racks.
- Automation lanes store points and modulation source metadata for browser-safe playback.

## Built-In Engines

The MVP focuses on original JavaScript/Web Audio instruments and effects:

- Neon Synth
- Sub Bass
- 808 Engine
- FM Bell
- Drum Synth
- Sampler Instrument
- EQ, compressor, limiter, delay, reverb, distortion, modulation, and analyzer effects

## Files And Rights

No copyrighted samples, SoundFonts, plugins, or third-party assets are bundled. Users should load or record audio they own or have permission to use.
