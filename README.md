# LOTTOMINDED ULTRA Brand Page

This folder is a standalone static brand page for the music app.

- Local route: `lottominded-ultra.io/`
- Studio app link: `./lottomind-stem-studio/index.html`
- Studio launch: use the Launch Full Studio button for the standalone browser app, or open Lottomind.one from the header.
- Motion hero background: `assets/video/lottomind-logo-sting.mp4` from the local Remotion intro render.
- Branded feature art: local LM reference assets and generated artwork in `assets/brand/`.

The page uses local brand assets only. No backend, paid API, cloud upload, or third-party copyrighted media is required.
